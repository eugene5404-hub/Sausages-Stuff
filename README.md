# Sausages & Stuff

A from-scratch mobile PWA for sausage-making formulas.

Features:
- Built-in fresh sausage formulas
- Seasonings in grams per kg
- Liquids in ml per kg
- Batch scaling
- Add, edit and delete personal recipes
- Add a recipe photo directly from the phone camera/gallery
- Photos are resized before being stored locally
- Installable PWA and offline shell
- Local device storage

This first version deliberately does not calculate curing salt or validated cured/fermented processes.
