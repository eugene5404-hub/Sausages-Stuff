Sausages & Stuff — Method Formatting Update

This update fixes recipe display formatting and adds automatic method-step numbering.

Changes:
- Method and Notes preserve line breaks and blank lines entered in the recipe form.
- Pressing Return after a numbered method line such as `1. Chill the meat` automatically starts `2. ` on the next line.
- Supports numbering with either `1.` or `1)` prefixes.

Install/update:
1. Extract the ZIP.
2. Upload the included `index.html` to the root of your existing `Sausages-Stuff` GitHub repository, replacing the old `index.html`.
3. Commit the change, then refresh the app. If an old cached version appears, close the app and reopen it, or refresh the site in Chrome.

Note: The GitHub connector could read the repository but was not permitted to write changes, so this package is prepared for manual upload. It has not been deployed to GitHub Pages.
